# Website motion recordings

Page recordings of the site's motion layer, for development-journal entries and
social posts about the website (the publicist covers the website from September 27;
see `docs/publicist/README.md`). A post uses one of these only as its private
review note allows, and says no more than the note's approved entry.

- **Kind:** Browser capture · local preview (silent)
- **Build:** kwilson21/thesuperhuman.us pull request 132 at commit `9fdb5b2`
- **Date:** September 27, 2026
- **Formats:** MP4 (H.264, 30 fps; prefer this where a network accepts video) and
  GIF (10 fps, 640 px desktop or 320 px phone wide, 96 colours) for networks that
  want a GIF. Phone recordings are captured at 2x.
- **Checked:** every recording was reviewed frame by frame. Recorded headless, so no
  address bar, console, cursor or private data appears. The pages show Tally's demo
  data capture (with its banner), the owner's Kaillera Next landing capture and the
  released Old News artwork, as the live pages do. No audio.
