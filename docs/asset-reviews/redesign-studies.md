Generated files total about 2.9 MiB, loaded as the reader explores; the initial page does not eagerly request every hidden study.
- Corrections: retained defects only as explicitly labelled historical material; removed duplicate introductory captures from the first and last milestones. Existing approved scene artwork elsewhere is unchanged.
