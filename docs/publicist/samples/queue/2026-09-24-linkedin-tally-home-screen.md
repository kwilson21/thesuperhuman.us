I'm building Tally, a budgeting app for my family, with a public demo on the way.

The Home screen answers one question first: how much is safe to spend this month? Below it, one sentence says what is off track, and one prompt points to the transactions that still need a category.

A rule I set early: AI suggests, code calculates, people decide. A small model suggests categories. Plain, tested code does every dollar of math and writes that status sentence.

Built with Claude Code on Cloudflare Workers. The screenshot is demo data for a fictional family.
