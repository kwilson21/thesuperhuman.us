# Product documentation

- [Project story requirements](project-story-requirements.md): canonical shared requirements for readable progress, visual roadmaps, history, automated publishing, and reusable project pages. Proposed until its documentation PR is accepted.
- `superpowers/specs/` and `superpowers/plans/`: historical website design and implementation documents.

Other project repositories should reference the shared requirements and supported version, not copy them. Project-specific goals and private evidence remain with their owning project.
