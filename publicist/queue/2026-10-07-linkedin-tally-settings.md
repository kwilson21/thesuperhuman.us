A new Tally household starts with no data, so it needs a way to set up categories and monthly budgets before real use.

Every new database now starts with 14 default categories. Settings lets you rename them, set a budget from this month on, reorder them and add new ones. Categories are archived, never deleted, so past transactions keep theirs.

Claude Code built it from design studies I picked. I capped the list at 50 categories so every screen shows them all without paging.

Built and tested on demo data: https://thesuperhuman.us/building/tally#tally-settings
